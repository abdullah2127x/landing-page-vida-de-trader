## 🌟 Key Features

- 📈 **Trading Curriculum & Strategy Hub**: Structured course pathways for Forex, Crypto, Indices, and Price Action technical analysis.
- 🎯 **Interactive Risk Calculators**: Financial positioning calculators, lot size tools, and risk-to-reward ratio estimators.
- 🌓 **Dynamic Theming Engine**: High-contrast dark trading station aesthetic and clean light mode powered by `next-themes`.
- 💫 **Fluid Visual Animations**: Smooth banner sliders, testimonial marquees, and chart transitions powered by Framer Motion, GSAP, and Swiper.
- 📱 **Modern UI Architecture**: Built with Radix UI, Base UI, Shadcn primitives, and Sonner notifications.

## 🛠️ Technology Stack

| Domain | Technology / Library | Purpose |
|---|---|---|
| **Framework** | [Next.js 16](https://nextjs.org/) (App Router) | Server Components and fast edge rendering |
| **View Library** | [React 19](https://react.dev/) | Modern reactive component tree |
| **Styling** | [Tailwind CSS v4](https://tailwindcss.com/) | Next-generation CSS utility framework |
| **Components** | Radix UI + Base UI + Shadcn | Accessible design system primitives |
| **Carousels & Animation** | Framer Motion + Swiper + Embla | Smooth responsive gestures and motion effects |
| **Charts** | [Recharts](https://recharts.org/) | Performance and market statistics charts |

## 🚀 Local Quickstart Guide

### Prerequisites
- Node.js 18+ and npm

### 1. Clone the Repository
```bash
git clone https://github.com/abdullahqureshi27/vida-trader-website.git
cd vida-trader-website
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Navigate to [http://localhost:3000](http://localhost:3000) in your browser.
